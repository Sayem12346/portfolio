# MD. Hafizur Rahman — Portfolio

Personal portfolio website built with **React + Vite**.

## 🚀 Deploy to Vercel (Step by Step)

### Step 1 — Install dependencies locally
```bash
npm install
npm run dev   # test locally at http://localhost:5173
```

### Step 2 — Push to GitHub
1. Create a new repo on github.com (e.g. `hafizur-portfolio`)
2. Run:
```bash
git init
git add .
git commit -m "initial portfolio"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/hafizur-portfolio.git
git push -u origin main
```

### Step 3 — Deploy on Vercel
1. Go to [vercel.com](https://vercel.com) → Sign up / Log in with GitHub
2. Click **"Add New Project"**
3. Import your GitHub repo
4. Framework: **Vite** (auto-detected)
5. Click **Deploy** — done! ✅

Your live URL will be: `https://hafizur-portfolio.vercel.app`

## 🛠 Tech Stack
- React 18 + Vite
- Pure CSS (no Tailwind needed)
- Cormorant Garamond + JetBrains Mono + Geist fonts
- Intersection Observer for scroll animations
- Custom cursor + scroll progress bar
